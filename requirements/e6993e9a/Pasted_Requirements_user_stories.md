# Generated User Stories

## User Stories

### US001
**As a** Admin, **I want** Create a user account, **so that** To manage and track employees and their roles within the organization

### US002
**As a** Admin, **I want** Assign roles to users, **so that** To ensure that users have the appropriate permissions to perform their tasks

### US003
**As a** Employee, **I want** View assigned tasks, **so that** To stay informed about their work responsibilities
